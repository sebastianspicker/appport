# Bundled fonts

Appport uses Source Sans 3 for body text and Manrope for headings. Both include the
characters needed for the English and German interface. The font files load from
the application itself, with system sans-serif fonts as a fallback.

| Font file | Source | License |
| --- | --- | --- |
| Source Sans 3 variable upright | [Adobe Source Sans](https://github.com/adobe-fonts/source-sans/blob/release/VF/SourceSans3VF-Upright.ttf) | [SIL Open Font License](source-sans-LICENSE.txt) |
| Manrope variable | [Google Fonts](https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf) | [SIL Open Font License](manrope-OFL.txt) |

The bundled files are unmodified. Keep their license notices with the fonts when
packaging the application.
