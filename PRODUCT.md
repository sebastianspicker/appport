# Product

## Register

product

## Users

People using managed Windows 11 devices who need to discover approved software and see approved updates for their assigned device without handling installers or administrative credentials.

## Product Purpose

Appport provides a narrow self-service view of the software and updates authorized in Relution for the current user and managed device. Success means the catalog is accurate, understandable, and safe while Relution remains authoritative for identity, device assignment, authorization, inventory, and deployment state.

## Brand Personality

Trustworthy, restrained, and direct. The interface should feel like a dependable Windows management tool that keeps attention on software status and the next valid action.

## Anti-references

Avoid consumer app-store merchandising, decorative dashboard chrome, novelty interactions, and ambiguous status presentation. Do not make unsupported installation, update, or security claims.

## Design Principles

- Make authorization and device-specific state explicit.
- Keep Available and Updates as the focused user-facing workflow.
- Prefer familiar Windows and web interaction patterns.
- Present version and action state without hiding operational detail.
- Preserve the native security boundary and communicate limitations plainly.

## Accessibility & Inclusion

Support keyboard navigation, visible focus, semantic labels and live status, forced-colors mode, dark mode, reduced visual ambiguity, and layouts that remain usable without horizontal scrolling at narrow viewports.
