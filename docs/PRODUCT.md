# Product principles

## Users

People using managed Windows 11 devices who need to discover approved software
and updates for their assigned device without handling installers or
administrative credentials.

## Purpose

Appport provides a narrow self-service view of the software and updates
authorized in Relution for the current user and managed device. Relution remains
authoritative for identity, device assignment, authorization, inventory, and
deployment state.

## Character

Trustworthy, restrained, and direct. The interface keeps attention on software
status and the next valid action.

## Avoid

Avoid consumer app-store merchandising, decorative dashboard chrome, novelty
interactions, and ambiguous status presentation. Do not make unsupported
installation, update, or security claims.

## Design principles

- Make authorization and device-specific state explicit.
- Keep Available and Updates as the focused user-facing workflow.
- Prefer familiar Windows and web interaction patterns.
- Present version and action state without hiding operational detail.
- Preserve the native security boundary and communicate limitations plainly.

## Accessibility

Support keyboard navigation, visible focus, semantic labels and live status,
forced-colors mode, dark mode, and layouts that remain usable without horizontal
scrolling at narrow viewports.
