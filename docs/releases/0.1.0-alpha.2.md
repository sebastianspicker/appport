# Release 0.1.0-alpha.2

Alpha.2 was a candidate for a limited pilot of the standalone Windows client. This
note describes that version; [release status](../../RELEASE_STATUS.md) covers the
current alpha.

## What it included

The repository contained the Tauri Windows client and its source-checking tools.
The client called a fixed HTTPS Relution endpoint from Rust. Its WebView displayed
the interface without network access.

## Build restrictions

CI and non-production builds used a fixed non-production HTTPS endpoint with
`APPPORT_RELUTION_WRITES_ENABLED=false`. The CI-generated MSI was unsigned and
could not be distributed. The client contained no Relution technical-account
credentials.

## Testing status

Source checks did not establish a signed Windows MSI, production certificate
trust, live service authentication, Relution permissions, deployment to managed
devices, or operation in a pilot.

See [Operations](../OPERATIONS.md) for the current build and testing process.
