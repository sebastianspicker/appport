# Release 0.1.0-alpha.2

Version 0.1.0-alpha.2 is a restricted managed-pilot candidate for the standalone Appport Windows client.

## Scope

The repository contains only the Tauri Windows client workspace and its source verification tooling.

The client communicates with the Relution API through a fixed HTTPS endpoint. Rust owns the client network path; the WebView remains network-isolated.

## Safety boundary

- Non-production and CI builds use a fixed non-production HTTPS endpoint.
- APPPORT_RELUTION_WRITES_ENABLED is false for CI and non-production builds.
- The CI MSI is unsigned and is not a distribution artifact.
- The client does not contain Relution technical-account credentials.

## Unverified gates

This release does not establish a signed Windows MSI, production certificate trust, live service authentication, Relution authorization, managed-device deployment, or restricted-pilot operation. See the [release status](../../RELEASE_STATUS.md) and [release checklist](../RELEASE_CHECKLIST.md).
