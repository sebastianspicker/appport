# Release 0.1.0-alpha.3

Version 0.1.0-alpha.3 is an unsigned, read-only qualification candidate for one approved Relution tenant. It is not suitable for general distribution.

## Candidate evidence

`candidateReady=true` requires successful source gates, a Windows MSVC MSI, its SHA-256, validated fixed qualification configuration, and a passing embedded-secret scan. A valid alpha.3 candidate records `signed=false` and `distributable=false`.

The build requires approved non-secret tenant origin, organization UUID, and native application UUID. It rejects missing, placeholder, malformed, or credential-bearing values. `APPPORT_RELUTION_WRITES_ENABLED=false` is embedded in the candidate and cannot be enabled at runtime.

## External qualification

Managed-device connection, catalog, icon, inventory, and background-check validation may be recorded later as read-only managed-tenant evidence. Destructive authorization, signing, and production qualification remain external and unqualified. Do not exercise deployment or administrative operations for this alpha.
