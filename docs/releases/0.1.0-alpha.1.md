# Release 0.1.0-alpha.1

Version `0.1.0-alpha.1` is a restricted managed-pilot candidate.

## Implemented in source

These items describe the source tree. They do not replace the Windows,
container, or live Relution gates in the
[current release status](../../RELEASE_STATUS.md).

- Windows 11 x64 client with Apps, Updates, and Installed views.
- Browser OIDC handoff with loopback callback and verifier exchange.
- Assigned-device matching and repeated assignment checks.
- Authorized Winget, Windows MSI, and Windows EXE catalog reads.
- Confirmed install and update requests with idempotent action tracking.
- SQLite audit history and explicit `unknown` state handling.
- Windows Credential Manager storage, scheduled update checks, and
  notifications.
- Single-replica broker container configuration with `/data` persistence and
  file-based production secrets.

## Restrictions

- The browser does not provide a software catalog.
- The broker supports one process and one SQLite database.
- The Windows client has no independent updater.
- Native sessions are portable bearer tokens.
- Initial Relution user resolution depends on a username claim.
- Live writes remain disabled until the deployment is qualified.

## Validation boundary

The repository has portable source evidence, but it does not establish a
signed Windows MSI, production container behavior, live Relution behavior,
encrypted restore, or managed-pilot operation.

See the [release checklist](../RELEASE_CHECKLIST.md) and
[current release status](../../RELEASE_STATUS.md).
